連結 GitHub

後台直接把變更寫進 GitHub repo（每次發佈都是一個 commit，可完整回滾）。需要一個 Fine-grained Personal Access Token：

  1. 開啟 GitHub → 建立 Fine-grained token
  2. Repository access 選 Only select repositories → ai-tools-platform
  3. Permissions → Repository permissions → Contents：Read and write
  4. Expiration 建議選 1 年，按 Generate token，複製貼到下面

Token 只存在這台裝置的瀏覽器（localStorage），不會上傳到任何地方。

卡片管理

拖曳 ⠿ 可排序；所有變更都先暫存，按右上「發佈變更」才會上線。

子頁面

像「ChatGPT 簡報風格指令庫」這樣的獨立頁面：一頁一個資料夾，各有自己的卡片資料與後台。建立後約 1 分鐘上線。

＋ 建立新頁面

網址會是 …/（代號）/；建立後點「後台」即可新增卡片與改文字。

檔案庫

集中管理網站用到的圖片與檔案。站內（GitHub）：速度快、跟網站一起版本控制，適合圖片與 20MB 以下檔案。雲端硬碟：適合安裝檔等大檔，全部集中在同一個資料夾。

🏠 站內檔案（assets/uploads）
拖曳檔案到這裡，或 上傳到站內 圖片自動壓縮（長邊 1600px）；上傳立即生效，不需按發佈
☁️ 雲端硬碟（Google Drive 集中資料夾）
開啟雲端資料夾 ↗
拖曳檔案到這裡，或 上傳到雲端資料夾 上限約 25MB；上傳後自動開啟「任何人可檢視」分享

版本記錄

每次發佈都是一個 commit。「還原」會把該版本的內容載入為暫存變更，再按發佈即可回滾。

編輯卡片

預覽即前台卡片實際效果

圖片可直接拖進來或用 ⌘V 貼上；點選圖片可調大小與對齊。影片支援 YouTube / Vimeo / Google Drive 連結。

置頂的項目會固定排在最新區前面（最新區共顯示 3 個）。
