改用 GitHub Token 登入

本後台與 平台後台 共用同一顆 GitHub token；已在平台後台登入過會自動登入。

  1. 開啟 GitHub → 建立 Fine-grained token
  2. Repository access 選 Only select repositories → ai-tools-platform
  3. Permissions → Contents 設為 Read and write
  4. 產生後複製貼到下面
