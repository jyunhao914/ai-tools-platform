Mini Cut — 影片剪輯轉檔工具(一鍵安裝)

輕量影片剪輯工具,專為長片場景設計。下載安裝即用,內建 FFmpeg 不需任何額外設定。

核心功能

  • ✂️ 去頭去尾 + 多段合併 — 拖曳入出點,串接多個影片,幀級精準
  • 🎬 畫面裁切 — 直接拖曳綠框 / 拖角縮放 / 對稱裁切保持置中
  • 📦 強力壓縮 — 可指定目標檔案大小(最小 1MB),兩階段編碼精準達標
  • 🎨 內建預設集 — YouTube / Reels / TikTok / LINE 小檔 / 極限壓縮 / Podcast,亦可自訂
  • ⚡ 硬體加速 — M 系列晶片極速編碼,Windows 自動偵測 NVENC / QuickSync
  • 📊 即時進度 + ↶ 復原(50 步)+ 📷 截圖 + 🛡️ 防睡眠 + 🔔 完成通知

下載

  • 📥 macOS Apple Silicon (M1/M2/M3 晶片):Mini Cut_0.8.0_aarch64.dmg(47 MB)
  • 📥 Windows 10/11 (64-bit):Mini Cut_0.8.0_x64-setup.exe(90 MB)
  • 📥 macOS Intel:建置中,完成後同步上線

安裝教學

🍎 macOS 安裝

  1. 下載 .dmg 檔,雙擊打開
  2. 把「Mini Cut」拖到「Applications」資料夾
  3. 第一次開啟會被擋(這是 Mac 安全機制):
    • 從 Launchpad 點 Mini Cut → 跳出「無法驗證開發者」 → 按 取消
    • 到 系統設定 → 隱私權與安全性
    • 頁面下方會看到「已封鎖 Mini Cut」 → 按右側 「仍要打開」
    • 跳出確認視窗 → 按 「打開」
  4. 之後從 Dock / Spotlight / Launchpad 打開都不會再被擋

💡 進階一鍵解鎖(可選):在「終端機」貼一行指令,完全跳過警告:

xattr -d com.apple.quarantine "/Applications/Mini Cut.app"

🪟 Windows 安裝

  1. 下載 .exe 檔,雙擊執行
  2. 跳出「Windows 已保護您的電腦」(SmartScreen 警告):
    • 點 「其他資訊」
    • 下方出現 「仍要執行」 按鈕 → 按下去
  3. 跟著安裝精靈一路按「下一步」即可
  4. 桌面 / 開始選單就會出現 Mini Cut 圖示,直接點開

(SmartScreen 警告原因和 Mac 一樣 — 此 app 沒做付費的 Microsoft 程式碼簽署。執行後不會再警告。)

快速上手(3 步驟)

  1. 拖入影片 — 拖到視窗或點選擇檔案
  2. 設定剪輯 — 播到開始位置按 I,結束位置按 O;按 Shift+空白 預覽
  3. 開始輸出 — 右側選預設集 → 點藍色「開始輸出」

必備快捷鍵

  • 空白 播放/暫停 · ←/→ 逐幀
  • I / O 設定入點 / 出點
  • Shift+空白 預覽剪輯區段
  • Cmd/Ctrl+Z 復原

系統需求

macOS 10.13+(Apple Silicon 完整支援) · Windows 10 1809 以上 / Windows 11(不支援 Win 7)。內建 FFmpeg,無需另裝。

FAQ

Q:可以壓到多小? 理論無下限,實測 5 秒短片可達 0.13 MB。但 1-2 小時影片塞 1MB 物理上不可能。

Q:為什麼會有「無法驗證開發者」/「SmartScreen」警告? 因為這是免費自製工具,沒花錢做 Apple Notarization / Microsoft Code Signing(每年費用)。功能完全正常,只需第一次手動打開一次。
