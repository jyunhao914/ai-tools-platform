系統需求與實測範圍

Mac 需 macOS 14 以上，Apple Silicon 已實測，Intel 未實機測試。Windows 需 64 位元，已在 Windows 11 ARM 搭配桌面 App 的 x64 Python 實測；x64 實體電腦尚未另行測試。Windows 原生 ARM Python 與 32 位元不適用此離線套件包。
