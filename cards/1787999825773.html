Presentation Maker｜從主題到簡報，一次完成

由 Jyunhao 製作，串起「材料整理 → 大綱規劃 → 視覺設計 → 簡報生成 → PPTX 交付」的完整工作流程。

  • 全程在 ChatGPT 生態內完成：使用自己的訂閱與可用額度，無須另外購買第三方 AI 服務或 API；仍受帳號方案與生圖額度限制。
  • 圖像式與可編輯式雙模式：可製作整頁視覺設計的圖像式簡報，或文字、形狀、表格與圖表可修改的可編輯簡報。
  • 完成即交付 PPTX：生成後直接組裝成 PowerPoint 檔案，不必自己逐張插圖、拼成簡報。
  • 內建多種預設風格：附風格縮圖，方便預覽與選擇。
  • 自動搭配或自訂風格：依主題自動規劃視覺，也可用文字描述想要的風格。
  • 儲存喜歡的風格：將本次風格設定與縮圖存入「我的風格庫」，下次直接選用。
  • 打包分享風格：可匯出風格 ZIP 備份、分享，再匯入使用；分享前請確認縮圖沒有私人內容。
  • 圖像式文字檢查與修正：核對生成文字、檢查疑似錯字並嘗試修復；仍有疑義時清楚標示位置並交付警告版，不保證百分之百零錯字。
  • 可編輯的 PowerPoint 圖表：依提供的資料與需求製作原生表格、圖表及流程圖，不只是一張截圖。
  • 依內容生成專屬插圖：可編輯模式先規劃版面與配圖位置，再生成可獨立移動、縮放或替換的圖片。
  • 多份資料整合：將多份材料整理、去除重複並整合成一份大綱，再接續製作簡報。
  • 材料轉成簡報：從文字、原始資料或既有簡報出發，整理內容並轉換為新的簡報。
  • 依主題與需求產出大綱：配合受眾、目的、頁數或時長規劃逐頁重點。
  • 大綱潤飾、還原與匯出：可修改現有大綱、依既有簡報還原逐頁大綱，或另存 TXT；確認後直接接續製作。

下載與適用條件

安裝包適用範圍與驗證狀態
② 下載 macOS 安裝包macOS 14 以上；含 Apple Silicon 與 Intel 套件。Apple Silicon 本機套件安裝已測；Intel 尚未實機測試。
② 下載 Windows x64 安裝包（測試版）Windows x64；已檢查包內元件，尚未完成 Windows x64 實機安裝驗證。ARM64／32 位元不適用。

Linux、手機、瀏覽器以及沒有本機 Plugin／生圖能力的環境不在本次安裝包支援範圍。組織管理政策可能限制本機程式或外掛。桌面 App、帳號與生圖額度需自行準備。

安裝步驟｜macOS

  1. 安裝新版 ChatGPT 桌面 App 並登入，先建立一個本機任務以完成執行環境初始化。
  2. 下載 Presentation-Maker-macOS.zip 並完整解壓縮。
  3. 雙擊資料夾內的 安裝 Presentation Maker.command。請勿只搬出這個檔案。
  4. 安裝器會檢查 Python／Node.js、補齊缺少的隨附套件、註冊外掛並確認已安裝且啟用。
  5. 看到成功訊息後，重新啟動 ChatGPT 桌面 App，建立新任務並選取 Presentation Maker。

安裝步驟｜Windows

  1. 安裝新版 ChatGPT 桌面 App 並登入，先建立本機任務初始化執行環境。
  2. 下載 Presentation-Maker-Windows.zip，按右鍵選「解壓縮全部」。不能在壓縮檔內直接執行。
  3. 雙擊 安裝 Presentation Maker.bat；它會啟動隨附的 PowerShell 安裝程式。
  4. 安裝器會檢查架構、Python 套件與 Tesseract 執行檔／DLL／繁中及英文語言包，再安裝外掛。
  5. 看到成功訊息後，重啟桌面 App，在新本機任務中選取外掛。

第一次提示「執行環境尚未初始化」：請在桌面 App 新任務輸入「請初始化本機 Python 與 Node.js 執行環境」，完成後再雙擊安裝檔。保留解壓縮資料夾供本機 marketplace 與後續更新使用。

遇到安全性攔截：先確認來源與下載完整性，再依系統提示允許這份檔案；不要全面停用 Gatekeeper、SmartScreen 或防毒。若被組織政策禁止，請由管理員處理。

完整路徑總覽

依你提供的材料與目的走不同路徑。點圖可開啟完整圖片。

① 提供什麼材料？

  • 只有主題／零散資料：先確認是否規劃大綱，再確認對象、用途與頁數；不是直接跳到簡報格式。
  • 已經有大綱：選擇潤飾修改或依此製作簡報。已明確指定製作時不重複詢問。
  • 上傳 PPTX／PDF：依目的選還原大綱或重新設計；PPTX 優先保留實際文字與可取得資產。PDF 的製作路徑為圖像式。
  • 多份材料：確認收到的資料，整合成一份新大綱；缺少事實以「[需補充]」標示，不自行捏造。

② 大綱確認後，才進入簡報製作

大綱使用「總標題＋第 N 頁｜頁面標題＋條列重點」，可包含對照表、視覺建議與提醒。大綱規劃不主動網路搜尋；確認後可選製作、潤飾或另存 TXT。

  • 圖像式：每頁由 ImageGen 產生完整視覺，組成全頁圖片的 PPTX；圖片中的文字不能直接逐字編輯。
  • 可編輯式：原生文字、形狀、表格與圖表可編輯；插圖為可移動、縮放或替換的獨立圖片，不是每個像素都能編輯。
  • 圖片處理：依來源可選沿用原圖、生成／重繪、或不要圖片。選生成時先規劃每頁版面與圖片空間，再生成符合內容的圖片；原則配圖，特殊過滿或不適合頁面才例外。

③ 選風格與建立自己的風格庫

真正需要選風格時，會提供縮圖與數字選項：0 自動、01–15 內建、16 自訂、17 起我的風格庫。續作沿用已確認風格，不會每次重問。

自動或自訂風格成品完成後，可選「儲存本次風格」並命名。保存位置是電腦 Documents／Presentation Maker／我的風格庫，內含可重用設定與縮圖；Windows 會使用系統實際 Documents 位置。下次選風格就能看到縮圖。預設風格不主動提示保存，仍可主動要求。

風格可匯出 ZIP 備份／分享、再匯入。縮圖可能含原簡報內容，分享前請確認。收藏保存的是視覺規則，不保證下次逐像素相同。公開外掛不包含開發者的私人風格庫。

常見問題

為什麼我在網站或手機找不到安裝方式？

這是本機桌面安裝包，不是 GPTs 連結。請先安裝新版 ChatGPT 桌面 App；只在瀏覽器登入同一帳號並不會取得本機執行能力。

中文字是否保證完全正確？

不保證。會核對來源與生成文字，OCR 只是輔助，不等於真相。整區修正、完整文字區重建後仍有疑義時，明示相關頁碼、位置與疑似錯字，並輸出帶警告的 PPTX；不無限重試，也不把疑似錯字宣稱通過。檔案結構損壞等問題則仍須修復。

更新會改掉我的風格庫嗎？

個人風格庫位於外掛之外，更新不覆蓋。下載新版並重跑安裝，重啟 App 後使用新任務載入新版本；進行中的任務不保證自動換版。

這次驗證了什麼？

原有 117 項自動化測試通過，生成／排版規則與原安裝版一致；另外檢查發布包與離線 Python 套件安裝。這不等於每種模型、帳號與 Windows 裝置都已實測，亦非 OpenAI 官方認證。
