手動下載安裝包（備用）

下載 macOS 版 下載 Windows 64 位元版

Mac 需 macOS 14 以上；Intel 與 已在 Windows 11 ARM 實測安裝。Windows ARM64／32 位元不適用。

手動安裝三步

  1. 安裝並登入新版 ChatGPT 桌面 App，下載上方外掛 ZIP 並完整解壓縮。
  2. Mac 雙擊 安裝 Presentation Maker.command；Windows 雙擊 安裝 Presentation Maker.bat。
  3. 看到成功訊息後重啟 App，在新本機任務中選取 Presentation Maker。

安裝遇到問題？展開查看
  • 不要在 ZIP 內執行，也不要只搬出安裝檔；請保留解壓縮資料夾。
  • 提示執行環境未初始化：在桌面 App 新任務輸入「請初始化本機 Python 與 Node.js 執行環境」，完成後再安裝。
  • 系統攔截時先確認來源，不要全面關閉防毒或安全設定。組織政策限制需由管理員處理。
  • 任務須能載入本機外掛、執行程式與使用 ImageGen；Work 尚未完成同等流程實測。
