# 離線簡報工作室（0.2.0 測試版）

桌面流程已改為 PySide6，正式入口是新版 Qt 介面。這是可供實際試用的測試版，不是整體計劃書所列功能都已完成的正式產品。新版修正「貼入大綱後無法繼續」流程，並修正頁標題與內文黏在同一行時會少辨識一頁的解析錯誤。

## 目前開發中的流程

本機測試包已建置於 `outputs/OfflinePresentationStudio-2026.09.26-qt.app`。開啟後執行：

1. 首頁選「貼上簡報大綱」，貼入後即時確認頁數與標題。
2. 按「下一步：設定簡報」，確認名稱與風格。
3. 建立專案、逐頁編輯、保存，再按「匯出 PowerPoint」。

大綱編輯使用 Qt 原生文字欄位，提供「從剪貼簿貼上」按鈕與原生右鍵選單；macOS 鍵盤貼上已在自動化測試中檢查，仍需解鎖桌面後人工確認。解析結果即時列出頁數與標題；無效時會顯示原因並停在原頁，不建立空白簡報。已用含表格、21 頁及黏行頁標題的大綱驗證頁數保留。匯入 PPTX、PDF、DOCX、TXT 走同一份本機解析器。匯出是可編輯式 PPTX，文字保留為 PowerPoint 文字物件。

## 模型狀態

- 圖片權重：本機 Qwen-Image-2.1 已下載，既有 Diffusers 後端有實機推論紀錄；Qt 新介面尚未提供圖片生成／修改操作。
- 文字權重：本機 Qwen3.8-27B MLX 權重存在。測試包內附經校驗的 `mlx-serve` 執行環境；本機文字生成曾通過實際推論 smoke test。執行時只綁 `127.0.0.1`，預設停用 MTP，完成後會停止子程序。文字模型權重未包含在 411 MB 測試包內，僅本機已有模型的 Mac 能使用 AI 草稿功能。

文字候選稿會先顯示給使用者檢視，接受前不會取代原文；拒絕或模型失敗時，原始內容保持不變。模型、來源文件與簡報內容不得傳至外部服務。使用本機 loopback API 不代表對網路其他裝置開放。

## 執行與測試

```sh
cd presentation-maker-offline
python3 -m pip install -e .
presentation-maker-offline-app
python3 -m pytest -q
```

關鍵核心模組位於 `presentation_maker_offline/`。正式入口是 `qt_ui.py`；`ui.py` 是舊 Tk 原型。版面樣式集中在 `export.py`。完整測試：`53 passed`。測試包不取代舊版 `.app`，請從上述新版路徑開啟；它仍不具備圖片生成、區域標記、對話編修、版本比較等整體規劃功能。
