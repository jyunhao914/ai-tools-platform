# 離線簡報工作室（本機試用版）

這是持續開發中的 macOS 桌面試用版，核心用途是把貼上的簡報大綱整理成投影片、用本機 Qwen-Image-2.1 為頁面生成配圖，最後輸出 PowerPoint。它尚未達到整體計劃書定義的正式完成標準。

## 快速開始

試用包：`outputs/OfflinePresentationStudio-2026.09.26-revisions.app`（0.4.2，Apple Silicon／arm64）。第一次開啟若 macOS 顯示安全提示，請在 Finder 對 App 按右鍵並選「打開」。

1. 貼上大綱；按「從剪貼簿貼上」或使用 `⌘V`，畫面會先顯示辨識頁數和標題。
2. 按「下一步：設定簡報」，確認名稱、視覺風格與 PPTX 輸出形式，再建立專案。
3. 貼入的大綱會依每頁內容自動設計排版：封面、流程、密集重點和迷思對照有不同呈現方式；文字修改後會自動重算。逐頁編輯器仍可手動微調圖文位置。三欄可拖曳寬度，畫布可按「放大預覽」。
4. 按「為尚無圖片的頁面配圖」批次生成，或「為這一頁重新生成配圖」。圖片以本機 Qwen-Image-2.1 推論，逐張存入專案並顯示在預覽中；可取消後續頁面而保留已完成頁面。
5. 選擇「可編輯式 PPTX」或「圖像式 PPTX」，按「匯出 PowerPoint」。前者保留文字與圖片物件，後者將每頁畫布存為完整投影片圖片。

編輯器上方的「版本比較／還原」可查看舊版與目前版本的逐頁文字、圖片差異。還原會另外建立新版本；舊版與還原前版本都保留。這是版本歷史基礎，尚未包含對話生成候選稿的逐項接受。

需要補充資料時，切到編輯器的「資料」分頁，可加入多個 PPTX／PDF／DOCX／TXT／圖片檔，或貼上文字；各份資料會顯示用途、範圍、解析預覽與版本。選擇一段文字後按「加入目前頁面」，確認才會插入並保留來源版本關聯。資料加入本身不改寫投影片；風格參考也不會當成正文插入。掃描 PDF 目前只會顯示無文字警告，尚未自動 OCR。

新建大綱及匯入的 TXT、DOCX、PDF 會依內容自動排版；既有 PPTX 會保留來源物件位置。內容多的頁面使用雙欄，含箭頭的流程頁使用步驟卡片，迷思與觀念以對照欄呈現，並保留底層可編輯原文。配圖提示詞會隨頁保存；字量可能超出頁面時匯出前會提示。編輯器也提供滑鼠拖曳區域標記、留言保存及重新開啟專案。標記目前是註記，不會自動改圖或改字。來源可匯入 PPTX、PDF、DOCX、TXT。

## 本機模型

- 圖片：需要本機完整 Qwen-Image-2.1 權重與相容的 PyTorch／Diffusers 環境。這台 Apple Silicon Mac 已以 MPS 實際執行過生圖；配圖介面、專案儲存及 PPTX 圖片匯出另有自動化整合測試。模型權重不裝進 `.app`，App 會使用此 Mac 上的模型。
- 文字：本機 Qwen3.8-27B MLX 權重存在時，可呼叫隨附的 `mlx-serve` 執行環境產生大綱候選。文字權重也不裝進 `.app`。AI 草稿會先供檢視，接受前不覆蓋原文。服務只監聽 `127.0.0.1`，不把簡報內容送到外部服務。

生圖是高記憶體與磁碟負載工作；此機測試時需約 31 GB 圖片模型檔案。第一次推論會載入模型，請等待狀態提示。模型未安裝或不完整時，功能應提示原因，不會默默改用雲端服務。

## 已驗證與尚未驗證

- 自動化測試：`73 passed`。涵蓋大綱貼上與 21 頁解析、依內容自動排版、編輯流程、資料版本／引用保存、版本比較與無破壞還原、標記儲存、配圖工作流程（使用假後端）、放大預覽和雙模式 PPTX 匯出。
- 原始碼與封裝 App 的端到端診斷均通過：兩頁大綱建立專案、含圖保存、兩種 PPTX 輸出和本機影像套件載入。封裝 App 另直接以 Qwen-Image-2.1／MPS 成功生成一張圖片；紀錄在 `outputs/封裝版驗收_0.4.2.json`。
- 封裝 App 已通過 Apple Silicon 簽章結構檢查；**尚未在已鎖定的 macOS 桌面上以滑鼠完成整套互動驗收**。需解鎖後實測貼上、右鍵選單、按鈕、逐頁套圖和 Keynote／PowerPoint 開檔。

仍待完成的範圍包括：新電腦模型安裝引導、完整來源定位與 OCR、來源排除／覆蓋檢查、個人風格庫、深入的逐物件編輯、對話式修改與版本比較、進階圖片修編、正式安裝簽署／公證、跨機安裝與效能驗收。請把本版本視為可供本機測試的試用原型，而非已完成的正式軟體。

## 從原始碼執行與測試

```sh
cd presentation-maker-offline
python3 -m pip install -e .
presentation-maker-offline-app
python3 -m pytest -q
```

新版 Qt 入口為 `presentation_maker_offline/qt_ui.py`；`ui.py` 是舊 Tk 原型。版面與 PowerPoint 匯出位於 `presentation_maker_offline/export.py`。
