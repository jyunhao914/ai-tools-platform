第一次使用，先裝外掛並連接 Drive

已經能在 Chat 選到 0.1.62，而且已連接自己的 Google Drive，就可以直接開始製作。

第一次安裝｜跟著兩張畫面操作
  1. 下載 ZIP，保留整個檔案

    按本頁上方「下載安裝包」，在 Google Drive 按下載，保留 presentation-studio-text-0.1.62.zip 原檔。

  2. 在 ChatGPT 上傳外掛

    用瀏覽器登入要做簡報的 ChatGPT 帳號，開啟「外掛程式」頁。點右上「新增」，選「上傳外掛程式封存檔」。

    選剛下載的 ZIP，按「新增外掛程式」。回到新的網頁對話，在輸入框鍵入 @Presentation Studio，點選搜尋結果中的外掛名稱。

  3. 建立自己的簡報工作區

    在已選外掛的 Chat 輸入「幫我設定簡報工作區」。依提示連接自己的 Google Drive。設定完成會看到「Presentation Studio」「製作紀錄」「我的風格庫」三個資料夾連結。之後製作簡報都用這組帳號。

已安裝舊版｜更新原本那一份

先查看原外掛的版本。若是自己上傳的舊版，可在網頁 Chat 選 Plugin Creator，附上新的 ZIP 和原外掛連結，送出下面這句。更新後核對原連結開啟的是 0.1.62。

請用這個 ZIP 把連結中的 Presentation Studio 更新到 0.1.62，沿用同一個外掛 ID。

若同事共用的是單位管理的外掛，請建立者更新同一份。更新後，同事從原有入口使用即可。

在網頁 Chat 選模式與設定

  1. 從「對話」開始

    開啟 ChatGPT 網頁版，在首頁選「對話」。在輸入框鍵入 @Presentation Studio，點選清單中的外掛。若這次會用到 Drive，也可輸入 @Google Drive 並選取。有原稿就附檔或貼上自己的 Drive 檔案連結。輸入「我要做簡報」或直接寫主題，按送出，接著就能選模式。

  2. 依手邊的材料選一種模式
    從主題或大綱製作
    有題目或已有大綱。說明要講給誰聽、講多久，逐頁看完大綱後按採用。
    把資料整理成簡報
    有報告、筆記或逐字稿。附上資料，檢查整理後的逐頁內容，再採用大綱。
    保留內容重新設計
    已有 PowerPoint 或 PDF。附上原稿，核對讀到的檔名和頁數。外掛預設沿用逐頁原文；單頁內容放不下時，可先看拆頁建議再決定。
  3. 在「製作設定」選成品形式
    圖像式
    每頁做成一張完整設計圖，適合直接播放。頁內的字和圖合在一起。
    可編輯・快速型
    以原文、原圖及資料排版，適合例會或後續常改的簡報。文字、表格與原生圖表可分別修改。
    可編輯・精緻型
    適合想保留編輯彈性，又要做出照片跨欄、去背小圖或分層底圖的簡報。照片可依各頁留白裁切，標題和內文仍可單獨編輯。
  4. 選圖片、版面和要拿的檔案

    若要重做舊簡報，下面三項可同時選。想拿兩種簡報檔，請在確認前指定「PowerPoint 和 Google 簡報」；若有可編輯圖表，一併指定「圖表試算表」。

    原有圖片怎麼處理？
    選「沿用原圖」「超擬真重繪原圖」或「重新配圖」。原始截圖、證據影像和數據圖表會保留。
    無圖頁要不要配圖？
    「維持無圖」保留純文字頁。「依內容自動配圖」讓外掛判斷哪些頁加圖有助理解。只想改某一頁，可展開「逐頁／逐圖調整」，對照原頁縮圖，在該頁或該圖旁填寫要求。
    圖片要什麼風格？
    選「寫實照片」「插圖」「依內容自動」，也可自行描述。另有「版面風格」可選整份簡報的配色、字體與編排，例如「07 企業提案」。
    範例｜把舊版節能報告改成可編輯的簡報

    附上自己的報告，選「保留內容重新設計」，再照下面這組需求填選，或在 Chat 直接說明。

    選可編輯・精緻型。設備照片超擬真重繪，無圖頁依內容自動配圖，圖片用寫實照片。保留原文、操作截圖和用電趨勢圖。請交付 PowerPoint、Google 簡報和圖表試算表。

  5. 按一次「確認設定，開始製作」

    核對摘要中的原稿、形式、配圖與交付項目，再按確認。隨即點卡上的「複製 Work 啟動指令」。若卡片收起，直接到自己剛送出的確認訊息，複製從「接續製作」開始的整段文字，包含後面的資料。這時就能前往 Work，不必等 Chat 再回答。

    舊卡沒有完整指令？看恢復步驟

到網頁 Work 貼上啟動指令

  1. 在剛才的 Chat 複製整段指令

    從設定卡或自己送出的確認訊息，複製以「接續製作」開頭的整段指令。指令含這次的私人交接文件、工作識別與設定資料；即使文字很長也要全部保留。若 Chat 直接列出定稿摘要和可複製指令，核對設定後即可把該指令帶到 Work。

  2. 另開一個分頁，首頁選「工作（Work）」

    保留原 Chat 分頁，另開 ChatGPT 首頁。使用同一個 ChatGPT 帳號，選「工作」開一個新的 Work 對話。在輸入框用 @ 選「Presentation Studio」。需要選 Drive 時，選回剛才的 Google 帳號。

  3. 貼上剛才那一整段，按送出一次

    Work 會讀回同一份原稿與設定，接手排版、生圖、組裝及轉檔。看到底稿或圖片預覽時，讓它在這個 Work 繼續執行；中途不用再送「繼續」。

如何知道已經交給 Work？

在 Chat 按確認後，還要把指令貼到 Work 送出。等 Work 對話顯示已接手這份工作，就可以在該處看進度、收成品。

做完去哪裡拿檔案？

回到貼啟動指令的那個 Work 對話，找最後的交付訊息。若選了兩種簡報且有可編輯圖表，會有以下三項。

PowerPoint（.pptx）
點檔案卡或下載連結，用 PowerPoint 開啟。可編輯形式能點選文字方塊；原生圖表可用「編輯資料」開啟檔內的工作表。
Google 簡報
點 Google 簡報連結，在瀏覽器直接開啟投影片，之後可以協作或播放。
圖表試算表
點 Google 試算表連結，查看或修改圖表的來源數據。修改後，在 Google 簡報點圖表的「更新」。若投影片另有可編輯的數值標籤，也要同步改字。試算表和簡報會放在同一個工作資料夾。

日後要找回成品，從自己的 Google Drive 開啟 Presentation Studio → 製作紀錄 → 這次的工作資料夾。如果製作時另有指定成品位置，請用交付訊息中的資料夾連結。

0.1.62 功能介紹

確認時就能帶走 Work 指令
三種模式都在網頁 Chat 完成設定，正式製作統一交給 Work。新版卡片在確認當下提供可複製的完整指令；若卡片送出後收起，可從剛送出的訊息取回。遇到 Chat 回覆空白，也能接著做。
同一頁可用不同圖片規則
例如左邊操作截圖沿用，右邊產品照片重繪。只填這兩個圖位的例外，其餘頁面沿用整份設定。
精緻型可以分層排版
大圖可依主體位置跨欄、滿版或局部裁切；小圖可用透明 PNG，圖示也可做成可調整的物件。需要特定效果時，可在確認前指定。
保留原文也能處理錯字與密頁
保留原文時，疑似錯字在交付訊息依頁列出。內容過密會先建議拆成幾頁，由你決定。成品固定不顯示投影片頁碼。
錯圖會排回去重做
某個圖位生圖失敗、主體錯誤或收到拼貼時，Work 先做其他頁，再回來補該圖。交付前檢查空白頁、原文、圖表標籤及 Google 轉檔後的字級與遮擋。

選預設版面，或沿用自己的風格

可讓外掛依內容搭配，也可預覽 15 款版面。找到喜歡的款式，回到 Chat 的版面風格欄填編號或名稱，例如「07 企業提案」。要沿用單位自己的設計，可在 Chat 說「我的風格庫」，選已儲存的名稱。

遇到狀況時怎麼做？

按完確認後空白、顯示「已停止思考」，或舊卡沒有指令

先看設定卡與自己剛送出的訊息。有「接續製作」開頭的完整指令，就複製整段，到同一帳號的網頁 Work 貼上送出。若舊卡只有「請存入待製作」或只有短識別，回到原 Chat 選用更新後的 Presentation Studio，傳送下面這句。

請沿用我剛確認的原稿和設定，補回這份簡報的完整 Work 啟動指令。

複製補回的整段指令，再到 Work 貼上送出。若回覆指出這份工作先前已被 Work 接手，直接從原 Work 對話查看進度或成品。

Chat 裡沒有選單，或找不到外掛

先確認在網頁「對話」及安裝外掛的帳號。在輸入框鍵入 @Presentation Studio 並點選結果。若外掛已回覆、選單卻沒有顯示，可直接輸入模式名稱，例如「保留內容重新設計」，再用文字回答它列出的設定。

原檔上傳失敗，或我剛改過同名檔案

把要用的版本存到自己的 Google Drive，確認目前連接的帳號能開啟，將該檔案的連結貼回設定中的 Chat。核對讀到的頁數以及你剛改的那一頁，再確認製作。

Work 說找不到工作，或 Google 要求權限

回到原 Chat，從設定卡或剛送出的訊息重新複製這次完整的啟動指令。核對 Work 使用同一個 ChatGPT 帳號及有權開啟交接文件的 Google Drive 帳號；有授權提示時完成連接，再回原 Work 接續這一份。

只看到圖片、PDF 或底稿，怎麼找正式成品？

回到原 Work 對話查看最新狀態，製作中就等它組裝完成。已顯示交付時，找最後訊息的 .pptx 檔案卡、Google 簡報和適用的試算表連結，也可查看該次工作資料夾。若訊息列出某項失敗，依該項原因處理，例如補上 Drive 存取權，再回同一份工作。
