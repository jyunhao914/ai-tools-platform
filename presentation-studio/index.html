01 / 功能

三種製作模式。

主題製成簡報

提供題目，先確認對象、用途與頁數或時間，再規劃大綱。

大綱製成簡報

沿用逐頁內容，可先修改再製作。

資料整理成簡報

把文件、PDF、海報或圖片整理成投影片內容。

重製現有簡報

PowerPoint（可編輯、圖像或混合）及圖像式 PDF；保留原文、頁數與順序重新設計。

輔助功能：還原逐頁文字大綱、分析配色與版面風格；可獨立完成。

02 / 安裝設定

下載、安裝，再完成初次設定。

  1. 下載 ZIP。使用本頁的 0.1.21 安裝檔。
  2. 安裝或更新。若帳號提供「匯入外掛／上傳 ZIP」，依介面提示匯入；請核對安裝完成的版號。
  3. 開新對話。輸入 @ 選取 Presentation Studio，先完成初次設定，再提供製作內容。

安裝後，先說這句話

請使用 studio-setup 完成簡報工作室初次設定，沿用已有的風格庫與製作紀錄，並說明哪些功能已就緒。

若出現「設定 Presentation Studio」按鈕，也可直接按下。需要雲端存檔或個人風格時，依提示連接自己的 Google Drive。

安裝與版本更新

下載完整 ZIP，於 ChatGPT「新增外掛程式」上傳，無須解壓縮。已安裝者請回外掛管理核對既有項目，依帳號介面提供的方式更新。出現同名提示時，不要以改 ZIP 檔名當作更新；完成後核對版號 0.1.21，開新對話使用。

使用條件

安裝入口與工具依帳號介面提供。Google Slides 與雲端風格保存需要連接本人的 Google Drive；無須自行架設 MCP。首次設定建立或沿用 Presentation Studio／製作紀錄與我的風格庫。

03 / 製作流程

依模式接續製作

  1. ① 從主題或大綱製作提供主題或大綱、對象、用途與頁數，採用大綱後選形式、圖片、文字、風格四項設定。
  2. ② 把資料整理成簡報上傳資料，確認整理後的大綱，再選四項製作設定。
  3. ③ 保留內容重新設計讀取原稿後直接選形式、圖片、風格三項。文字鎖定保留原文，保留頁數與頁序，不再還原大綱或要求採用。

可使用互動選單或自由輸入文字。

04 / 圖片與風格

編輯方式、圖片和文字，分別選擇。

可編輯式

文字與可支援的物件可繼續編輯。

圖像式

每頁為完整圖片，文字無法逐字編輯。

  • 圖片：不用圖片、沿用原圖、超擬真重繪、重新生成配圖；依來源提供可用選項。
  • 文字：①②可選保留原文或允許潤飾；③固定保留原文。
  • 風格：自動、15 款預設、我的風格庫或自訂描述；在風格網頁點選卡片，看到「✓ 已複製」後回對話貼上，例如「預設風格：02 藍色醫療」。也可直接輸入編號。

05 / 成品交付

下載成品，風格可選擇收藏。

完成實際 PPTX 後提供下載；建立 Google Slides 成功時，另提供開啟連結。Drive 保存結果分開顯示，未存入雲端不會標示已保存。

交付後輸入「儲存風格」即可收藏。下次輸入「我的風格庫」或上傳中文檔名的風格 JSON 帶入。表單若出現傳送確認視窗，按「傳送」即可；傳送失敗時保留已填內容並提供重試。
