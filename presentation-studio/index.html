第一次使用，先裝外掛並連接 Drive

已經能在 Chat 選到 0.1.74，而且已連接自己的 Google Drive，就可以直接開始製作。

第一次安裝｜跟著兩張畫面操作
  1. 下載 ZIP，保留整個檔案

    按本頁上方「下載安裝包」，在 Google Drive 按下載，保留 presentation-studio-text-0.1.74.zip 原檔。

  2. 在 ChatGPT 上傳外掛

    用瀏覽器登入要做簡報的 ChatGPT 帳號，開啟「外掛程式」頁。點右上「新增」，選「上傳外掛程式封存檔」。

    選剛下載的 ZIP，按「新增外掛程式」。回到新的網頁對話，在輸入框鍵入 @Presentation Studio，點選搜尋結果中的外掛名稱。

  3. 建立自己的簡報工作區

    在已選外掛的 Chat 輸入「幫我設定簡報工作區」。依提示連接自己的 Google Drive。設定完成會看到「Presentation Studio」「製作紀錄」「我的風格庫」三個資料夾連結。之後製作簡報都用這組帳號。

已安裝舊版｜更新原本那一份

先查看原外掛的版本。若是自己上傳的舊版，可在網頁 Chat 選 Plugin Creator，附上新的 ZIP 和原外掛連結，送出下面這句。更新後核對原連結開啟的是 0.1.74。

請用這個 ZIP 把連結中的 Presentation Studio 更新到 0.1.74，沿用同一個外掛 ID。

若同事共用的是單位管理的外掛，請建立者更新同一份。更新後，同事從原有入口使用即可。

在 App 或網頁 Chat 選模式與設定

  1. 從「對話」開始

    開啟 ChatGPT App 的一般對話，或在 ChatGPT 網頁版首頁選「對話」。在輸入框鍵入 @Presentation Studio，點選清單中的外掛。若這次會用到 Drive，也可輸入 @Google Drive 並選取。有原稿就附檔或貼上自己的 Drive 檔案連結。輸入「我要做簡報」或直接寫主題，按送出，接著就能選模式。

  2. 依手邊的材料選一種模式
    從主題或大綱製作
    有題目或已有大綱。說明要講給誰聽、講多久，逐頁看完大綱後按採用。
    把資料整理成簡報
    有報告、筆記或逐字稿。附上資料，檢查整理後的逐頁內容，再採用大綱。
    保留內容重新設計
    已有 PowerPoint 或 PDF。附上原稿，核對讀到的檔名和頁數。外掛預設沿用逐頁原文；單頁內容放不下時，可先看拆頁建議再決定。
  3. 在「製作設定」選成品形式
    圖像式
    每頁做成一張完整設計圖，適合直接播放。頁內的字和圖合在一起。
    可編輯・快速型
    以原文、原圖及資料排版，適合例會或後續常改的簡報。文字、表格與原生圖表可分別修改。
    可編輯・精緻型
    適合需要視覺構圖的簡報。可讓大標疊在出血照片上、讓去背物件跨過底色邊界，或用能單獨改色的線條圖示辨認各個步驟。圖表和截圖則優先保留可讀空間。
  4. 選圖片、版面和要拿的檔案

    若要重做舊簡報，下面三項可同時選。想拿兩種簡報檔，請在確認前指定「PowerPoint 和 Google 簡報」；若有可編輯圖表，一併指定「圖表試算表」。

    原有圖片怎麼處理？
    選「沿用原圖」「超擬真重繪原圖」或「重新配圖」。原始截圖、證據影像和數據圖表會保留。
    無圖頁要不要配圖？
    「維持無圖」保留純文字頁。「依內容自動配圖」讓外掛判斷哪些頁加圖有助理解。只想改某一頁，可展開「逐頁／逐圖調整」，對照原頁縮圖，在該頁或該圖旁填寫要求。
    圖片要什麼風格？
    選「寫實照片」「插圖」「依內容自動」，也可自行描述。另有「版面風格」可選整份簡報的配色、字體與編排，例如「07 企業提案」。
    範例｜把舊版節能報告改成可編輯的簡報

    附上自己的報告，選「保留內容重新設計」，再照下面這組需求填選，或在 Chat 直接說明。

    選可編輯・精緻型。設備照片超擬真重繪，無圖頁依內容自動配圖，圖片用寫實照片。保留原文、操作截圖和用電趨勢圖。請交付 PowerPoint、Google 簡報和圖表試算表。

  5. 按「確認設定，取得 Work 指令」

    核對摘要中的原稿、形式、配圖與交付項目，再按這個按鈕。指令會直接顯示在卡片上，點「複製 Work 啟動指令」取走整段。這一步只在卡上操作，Chat 不會送出訊息或開啟新一輪對話。

    若 App 或網頁沒有可操作的卡片，完成設定後，直接從助理定稿摘要旁的獨立指令區複製。可按程式碼區的複製鍵，或手動選取從「接續製作」起的整段文字，在手機按「複製」、電腦按複製快捷鍵。

    舊卡沒有完整指令？看恢復步驟

到網頁 Work 核對原稿，送出啟動指令

  1. 在剛才的 Chat 複製整段指令

    複製從「接續製作」起的完整內容。若已存好私人交接文件，指令會帶文件連結與工作識別；若 Chat 無法寫入或讀回交接文件，指令會直接帶入本次原稿的版本線索和已確認設定，供你貼到 Work。需要帶入附件時，複製後的指令也會列出要選的原稿。貼進 Work 後，先確認輸入框內同時有指令和該份附件，再按傳送。

  2. 從 App 或瀏覽器前往網頁「工作（Work）」

    保留原 Chat。從 App 操作時，複製後打開瀏覽器；本來就在瀏覽器時，另開一個分頁。前往 ChatGPT 首頁，使用同一個 ChatGPT 帳號，選「工作」開一個新的 Work 對話。在輸入框用 @ 選「Presentation Studio」。需要選 Drive 時，選回剛才的 Google 帳號。

  3. 看這次的原稿從哪裡來
    從 Chat 上傳或 ChatGPT 檔案庫選的原稿
    若交接說明未確認有可讀的 Drive 原稿，點 Work 輸入框下方的「檔案」。在「搜尋空間中的檔案」輸入完整檔名，勾選這次在 Chat 用的版本。收起選單後，確認輸入框內已出現該檔名的附件標籤。若有同名檔，先對照原 Chat 的附件預覽與修改內容。
    交接說明已確認可讀的 Drive 原稿，或這次只用定稿大綱
    指令已帶入核對過的 Drive 來源，或大綱已包含製作所需的全部內容，就直接進下一步。
  4. 貼上完整啟動指令，按「傳送」一次

    上一步有選檔時，再看一眼輸入框，確認同時有原稿附件和完整指令，再送出。請在這個 Work 查看製作進度和最後的交付訊息。

送出後怎麼核對原稿？

從檔案庫選檔時，你送出的 Work 訊息裡會出現可點選的檔名，右側「來源」也可以開啟原稿預覽。

做完去哪裡拿檔案？

回到貼啟動指令的那個 Work 對話，找最後的交付訊息。若選了兩種簡報且有可編輯圖表，會有以下三項。

PowerPoint（.pptx）
點檔案卡或下載連結，用 PowerPoint 開啟。可編輯形式能點選文字方塊；原生圖表可用「編輯資料」開啟檔內的工作表。
Google 簡報
點 Google 簡報連結，在瀏覽器直接開啟投影片，之後可以協作或播放。
圖表試算表
點 Google 試算表連結，查看或修改圖表的來源數據。修改後，在 Google 簡報點圖表的「更新」。若投影片另有可編輯的數值標籤，也要同步改字。試算表和簡報會放在同一個工作資料夾。

日後要找回成品，從自己的 Google Drive 開啟 Presentation Studio → 製作紀錄 → 這次的工作資料夾。如果製作時另有指定成品位置，請用交付訊息中的資料夾連結。

0.1.74 功能介紹

下面兩份 PowerPoint 都選了「可編輯・精緻型」和「依內容自動配圖」。點圖可放大查看封面、步驟和結尾三頁。

在 Chat 取指令，在 Work 開始製作
App 與網頁的普通 Chat 都能交出本次設定。卡片可操作時，在卡內複製指令；介面只顯示文字時，就從回覆的獨立指令區複製。兩種方式都是到 Work 貼上送出才開工。
純文字指令也能搭配私人原稿
設定可以整段複製。若你已同意使用本人的私人工作資料夾，Chat 會先讀原始 PowerPoint，核對內容後把原稿交給 Work。原稿的存放方式與設定的複製方式可分別選擇。
讓 Work 讀到這次選定的原稿
原稿僅在 Chat 或檔案庫時，交接說明會提示你在 Work 選回同一份，和啟動指令一起送出。若交接已帶有核對過的私人 Drive 原稿，Work 可直接從該來源讀取。
同一頁可用不同圖片規則
例如左邊操作截圖沿用，右邊產品照片重繪。只填這兩個圖位的例外，其餘頁面沿用整份設定。
無圖頁也能用精緻型
選「可編輯・精緻型」及「維持無圖」即可。Work 依原文安排閱讀順序，例如把取書流程排成「預約、通知、領取」的閱讀順序，把兩家分館的開放時間並排對讀。中文大標也會依欄寬調整換行，例如讓最後一個字回到同一行。你只需要填想例外處理的頁面。
帶回精緻型設定與可編輯圖表
在 Chat 核對摘要後，將完整指令貼到 Work。Work 讀回原稿後會按這份設定排版。重繪的浮動小圖保留透明輪廓；若簡報有圖表並且同時選 Google 簡報與試算表，可從投影片裡的連結圖表開啟來源資料，更新後再回投影片重新整理。
想看到主圖、去背小圖和 icon
選「可編輯・精緻型」，再把「無圖頁要不要配圖」選為「依內容自動配圖」。想要攝影質感就選「寫實照片」，想要手繪媒材就選「插圖」。Work 會按內容取景，並在適合的步驟選用可編輯圖示。只有想指定某頁某張圖時，才需要填逐圖調整。
精緻型可以分層排版
大圖可依主體位置跨欄、滿版或局部裁切；小圖可用透明 PNG，圖示也可做成可調整的物件。需要特定效果時，可在確認前指定。
保留原文也能處理錯字與密頁
保留原文時，疑似錯字在交付訊息依頁列出。內容過密會先建議拆成幾頁，由你決定。成品固定不顯示投影片頁碼。
錯圖會排回去重做
某個圖位生圖失敗、主體錯誤或收到拼貼時，Work 先做其他頁，再回來補該圖。交付前檢查空白頁、原文、圖表標籤及 Google 轉檔後的字級與遮擋。

選預設版面，或沿用自己的風格

可讓外掛依內容搭配，也可預覽 15 款版面。找到喜歡的款式，回到 Chat 的版面風格欄填編號或名稱，例如「07 企業提案」。要沿用單位自己的設計，可在 Chat 說「我的風格庫」，選已儲存的名稱。

遇到狀況時怎麼做？

已送出設定，卻只看到「轉接未獲接受」或沒有指令

先查看原設定卡或舊版當時送出的訊息。已有「接續製作」開頭的完整指令，就到同一帳號的網頁 Work，依原稿來源選檔或直接啟動。若 App 把設定傳回 Chat，只回覆「轉接未獲接受」、畫面空白或顯示「已停止思考」，回原 Chat 選用更新後的 Presentation Studio，貼下面這句即可。

請沿用我剛確認的原稿與全部設定，給我可以直接複製到 Work 的完整指令。若這裡無法儲存交接文件，請把原稿版本資料與設定放進指令，並說明是否要在 Work 附上同一份原檔。

複製補回的整段指令，再依上方步驟到 Work 核對原稿、貼上送出。若回覆指出這份工作先前已被 Work 接手，直接從原 Work 對話查看進度或成品。

Chat 裡沒有選單，或找不到外掛

先確認 App 或網頁目前開的是一般「對話」，使用當初安裝外掛的帳號。在輸入框鍵入 @Presentation Studio 並點選結果。若外掛已回覆、選單卻沒有顯示，可直接輸入模式名稱，例如「保留內容重新設計」，再用文字回答它列出的設定。

原檔上傳失敗，或我剛改過同名檔案

把要用的版本存到自己的 Google Drive，確認目前連接的帳號能開啟，將該檔案的連結貼回設定中的 Chat。核對讀到的頁數以及你剛改的那一頁，再確認製作。

Chat 已經看過原稿，進 Work 還要選一次嗎？

如果當初從 Chat 上傳或從 ChatGPT 檔案庫選檔，且交接時沒有已核對的 Drive 原稿，就要在新 Work 再選一次。點「檔案」→「搜尋空間中的檔案」，勾選這次的原稿。看到輸入框出現可點選的檔名，再貼啟動指令，同一則送出。若交接已附可驗證的 Drive 來源，或已確認的大綱足以直接製作，就只需送出啟動指令。

已經送出指令，Work 認得檔名，卻說下載失敗或發生 DNS 錯誤

留在原來的 Work，查看你剛送出的訊息裡有沒有可點選的原稿附件。如果只有指令文字，點輸入框的「＋」→「從檔案庫加入」，選取本次版本，再按「新增至對話」。看到檔名出現在輸入框後，加上「沿用先前設定，以這份原稿接續」，一起送出。如果剛才送出的訊息已經有正確附件，Work 會先讀這個對話收到的檔案。若仍只能看到預覽，且取檔持續失敗，改用「上傳檔案」從裝置選取這次的 PowerPoint，或貼本人私人 Drive 內這份 PowerPoint 的檔案連結。設定可以沿用。如果 Work 仍讀不到原始檔，但你已允許工作使用私人 Google 簡報，原設定 Chat 可以用已驗證的同一份 PowerPoint 準備 Google 格式的工作副本，核對原文、備註、表格與圖中文字後，再由 Work 排版及交付。

Work 說找不到工作，或 Google 要求權限

回到原 Chat，從設定卡或助理的獨立指令區重新複製這次完整的啟動指令。核對 Work 使用同一個 ChatGPT 帳號及有權開啟交接文件的 Google Drive 帳號；有授權提示時完成連接，再回原 Work 接續這一份。

只看到圖片、PDF 或底稿，怎麼找正式成品？

回到原 Work 對話查看最新狀態，製作中就等它組裝完成。已顯示交付時，找最後訊息的 .pptx 檔案卡、Google 簡報和適用的試算表連結，也可查看該次工作資料夾。若訊息列出某項失敗，依該項原因處理，例如補上 Drive 存取權，再回同一份工作。
