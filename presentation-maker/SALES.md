# 下載入口設定

編輯同資料夾的 `sales.json` 並發布即可切換，全站三個下載入口共用。

- `mode: "paid"`：顯示價格及蝦皮購買連結。
- `mode: "free"`：開放下載；`freeUntil` 可填例如 `2026-09-30T23:59:59+08:00`，到期自動恢復購買視窗。填 null 代表不設截止時間。
- `mode: "paused"`：暫停入口，不顯示購買按鈕。
- `price`：數字售價。
- `announcement`：購買視窗的說明文字。
- `purchaseUrl`：蝦皮商品網址。

此設定只管理網頁入口，不提供檔案存取授權。公開 GitHub Release、指南及程式碼仍可被直接存取。本次未刪除或轉移公開資產，也沒有收集買家個資。
